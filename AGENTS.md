# OpenPLC Editor

OpenPLC Editor is a wxPython (GTK3) desktop IDE for writing IEC 61131-3 PLC programs
for the OpenPLC Runtime. It is a fork of Beremiz + MatIEC. The Python IDE lives in the
`editor/` git submodule; the C-based `iec2c` IEC compiler lives in the `matiec/` submodule.

Standard setup/run/test commands are documented in `README.md`, `install.sh`, and
`editor/README.md`. Prefer those as the source of truth.

## Cursor Cloud specific instructions

- This is a GUI desktop app, not a web/server app. It renders on X11 display `:1`
  (already available in the cloud VM). Always run it with `GDK_BACKEND=x11`.
- Python: the project targets Python 3.9. A ready-to-use virtualenv is at `.venv/`
  (created with `python3.9`). Use `.venv/bin/python3` to run anything, or `source .venv/bin/activate`.
- Run the IDE with the generated launcher: `./openplc_editor.sh` (it activates `.venv`,
  sets `GDK_BACKEND=x11`, and runs `editor/Beremiz.py`). This launcher is gitignored and
  regenerated by `install.sh`; if it is missing, run `install.sh` or recreate it manually.
- wxPython is installed from the prebuilt wheel index
  `https://extras.wxpython.org/wxPython4/extras/linux/gtk3/ubuntu-24.04` because plain
  `pip install wxPython` builds from source on Linux (very slow). The pinned
  `wxPython==4.2.0` in `install.sh` has no wheel for this index; the newest wheel (4.2.x)
  is used instead and works.
- `iec2c` (the MatIEC compiler) must exist at `editor/arduino/bin/iec2c`. A prebuilt
  x86_64 binary is committed in the `editor` submodule, and `install.sh` overwrites it with
  a freshly compiled one from `matiec/`. Recompiling MatIEC needs `bison`, `flex`,
  `autoconf`, `automake`, and a C++ toolchain.
- Harmless startup noise: GTK "Could not load a pixbuf ... checkbox-checked-symbolic.svg"
  and wx "Adding duplicate image handler" warnings can be ignored.
- No automated unit-test suite is wired up for routine use here. Test scripts live under
  `editor/tests/` (see `editor/tests/Makefile`) but require extra tooling; validate changes
  by launching the IDE and exercising it.
